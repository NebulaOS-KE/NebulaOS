# NebulaOS OrcaSlicer profiles (Ender-3 V3 KE, 0.4 mm nozzle)

> **A starting point, not a perfect tune.** These are the profiles we print with on our own KE.
> They work well for us, but every printer and every spool is a little different. Use them as a
> good starting point, then calibrate flow and pressure advance for your own filament and adjust
> from there.

`NebulaOS-Ender3V3KE-OrcaSlicer.orca_printer` is the bundle to import in OrcaSlicer 2.5.0 or newer
(**File → Import → Import Configs…**). `profiles/` holds the same profiles unpacked, so changes
can be reviewed. Step by step:
[Quickstart: OrcaSlicer profiles](https://github.com/NebulaOS-KE/NebulaOS/wiki/Quickstart-OrcaSlicer).

| Type | Contents |
|---|---|
| Printer (1) | Creality Ender-3 V3 KE 0.4 nozzle - NebulaOS |
| Filaments (4) | PLA @NebulaOS, PETG @NebulaOS, PETG-CF @NebulaOS, TPU @NebulaOS |
| Processes (16) | 0.12 Fine, 0.16 Optimal, 0.20 Standard and 0.24 Draft, each for PLA, PETG, PETG-CF and TPU |

They build on Creality's own Ender-3 V3 KE presets in OrcaSlicer, which must be installed.
