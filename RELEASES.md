# Releases

Published releases are on the [Releases page](https://github.com/NebulaOS-KE/NebulaOS/releases);
each one names the NebulaOS-firmware commit it was built from and carries its
`release-manifest.txt` and `build-manifest.txt` (every component's exact source).

How a release is built: [README](README.md#how-a-release-is-made) and
[`.github/workflows/release.yml`](.github/workflows/release.yml).

The `releases/` folder holds notes from before the first numbered release (2026-08); they are
history, not the current state.
